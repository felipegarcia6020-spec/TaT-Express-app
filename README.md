# TaT Express - Logística y Entregas

Aplicación móvil de logística y repartos en formato Tienda a Tienda (TaT) con navegación por mapa interactivo Leaflet, panel de supervisión, módulo de arqueo y cierre de caja por denominación, y rol GM maestro independiente.

## Estructura del Proyecto para GitHub y Capacitor

```text
tat-delivery-app/
├── www/
│   ├── index.html        # Aplicación Single-Page Completa
│   ├── manifest.json     # Manifiesto PWA
│   └── app.js            # Lógica de la aplicación
├── capacitor.config.json # Configuración de Capacitor Native Wrapper
├── package.json          # Dependencias y Scripts
└── README.md             # Guía de Instalación
=======
# TaT-Express-app
TaT Express es la app móvil ideal para logística Tienda a Tienda (TaT). Optimiza tus rutas con mapas interactivos, gestiona entregas, registra pagos en efectivo y transferencias (Nequi, Daviplata, Breve), realiza cierres de caja y mantén un monitoreo en tiempo real con supervisión y botón SOS.
